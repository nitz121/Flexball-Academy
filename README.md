# Flexball Academy ⚽

Flexball Academy is an interactive football-themed game for learning CSS Flexbox. Players solve tactical drills by changing Flexbox properties until the team formation matches the instruction.

## Features

- 10 football-themed Flexbox levels
- Clubs including Real Madrid, Barcelona, Bayern Munich, Liverpool, Manchester City, PSG, Inter Milan, AC Milan, Juventus, and Arsenal
- Real Football Legends
- Interactive controls for `flex-direction`, `justify-content`, `align-items`, and `flex-wrap`
- Immediate visual updates on the football pitch
- Detailed tactical instructions, answer validation, feedback, and level progression
- Score system based on the number of attempts per level
- Saved score, attempts, selected controls, and completed levels using `localStorage`
- Training Ground navigation for returning to completed levels
- Restart Academy option available during the game and after completion
- Responsive interface with a consistently proportioned pitch

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No external JavaScript libraries are used. The game board itself is built with Flexbox.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select **Start Training** and begin solving the drills.

## How to play

1. Read the tactical instruction for the current team.
2. Select values for the Flexbox controls.
3. Press **Check Formation**.
4. A correct formation unlocks the next level; incorrect attempts can be adjusted and tested again.
